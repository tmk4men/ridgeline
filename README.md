# RIDGELINE（リッジライン）

1.6km 四方の谷で、6人の狙撃手 CPU と撃ち合う一人称の狙撃戦。ブラウザで遊ぶ（PC・スマホ横画面）。

## 遊ぶ

https://tmk4men.github.io/ridgeline/

## ルール

- 敵の狙撃手を6人とも倒せば勝ち。自分は胴に2発（頭は1発）で負け
- 弾は秒速820m。重力で落ち、空気抵抗で遅くなり、風で流れる。遠いほど届くまで時間がかかる
- ゼロイン（Q / E）を距離に合わせると、照準の中心に当たる。スコープの下に距離計の値が出る
- 構えると息で照準が揺れる。Shift で息を止めると揺れが小さくなる（6秒まで。切れたら離して戻るまで止められない）
- 立ち・しゃがみ・伏せで揺れと見つかりやすさが変わる。動くと見つかりやすい。木の陰は見つかりにくい
- 撃つと銃声で位置がばれる（音の届く遅れの後、敵がだいたいの場所を知る）
- 敵は構えるとスコープが光る。気づかない時間が続くと、高い所や木の陰を選びながら詰めてくる
- ボルトアクション（1発ごとに1.4秒）、弾倉5発、装填3.2秒

## 操作

| | PC | スマホ（横画面） |
|---|---|---|
| 移動 | WASD（Shift で走る） | 左スティック |
| 視点 | マウス | 画面をなぞる |
| 構える / 倍率 | 右クリック / ホイール（8倍・16倍） | 構え |
| 撃つ | 左クリック | 撃つ |
| 息を止める | Shift（構え中） | 息 |
| 姿勢 | C しゃがむ / Z 伏せる | 姿勢 |
| ゼロイン | Q / E | ゼロ＋ / ゼロ－ |
| 装填 | R | 装填 |

## 開発

```bash
node server.mjs          # http://localhost:5190
node test.mjs            # ロジック19項目（弾道・ゼロイン・風・息・見つかりやすさ・敵・勝敗）
node shot.mjs <場面>     # title / play / scope / scope12 / target / target-glint / result / land（844x390 webkit）
node playtest.mjs 120    # 実時間で1試合（自動で敵を探して撃つ）
node release.mjs         # 公開の前にキャッシュバスターを付け直す
```

`src/sim.js` がロジック（three に依存しない・固定60Hz）、`src/main.js` が描画・入力・音・画面。
